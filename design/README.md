## Design language

- **Brand:** Sports Mart (serif wordmark, deep navy blue)
- **Surfaces:** Light gray / white, generous whitespace
- **Primary CTA:** Solid navy blue, large, high-contrast white label
- **Secondary CTA:** White with navy outline
- **Audience cues:** Large type, labeled icons, clear stock text
