# Phase 05 — Accessibility guidelines

Baseline for all screens in Phases 05–06.

## Typography & color

- Body ≥ 18px; important prices/names larger.
- Line length comfortable; generous spacing between cards.
- Contrast: aim for WCAG AA or better for text and buttons.
- Do not rely on color alone for stock status (include the word “In stock” / “Out of stock”).

## Controls

- Primary buttons ≥ 48px height, full text label.
- Secondary actions also labeled.
- Form controls large enough for touch / reduced precision.

## Motion

- Minimal animations.
- Respect `prefers-reduced-motion`.
- No auto-playing carousels on recommendations.

## Content

- Short product descriptions.
- Recommendation explanations always visible (not tooltip-only).
- Confirmation dialogs use plain language (“Your order is confirmed”).

## Navigation

- Persistent header with Home, Recommendations, Cart (with text).
- Category landings linked in plain text: All Sports, Equipment, Clothing, Footwear, Accessories.
- Cart shows item count as text, not badge-only.
- Left Filter band uses large labeled chips (not tiny checkboxes) and an **Apply filters** button.
